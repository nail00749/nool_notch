# План реализации

## Этап 1 — основа приложения

- Создать нативный macOS target.
- Добавить AppKit-координатор borderless-окна и позиционирование в верхней части экрана.
- Реализовать compact/expanded state и переключатель панелей.
- Добавить минимальную тему и базовую анимацию раскрытия.

## Этап 2 — модель панелей и квот

- Ввести `PanelID` и реестр панелей.
- Ввести `QuotaProvider`, `QuotaSnapshot` и `QuotaWindow`.
- Добавить mock-провайдеры ChatGPT Subscription и Ollama Cloud для разработки UI.
- Отобразить remaining/reset/status/last updated.

## Этап 3 — реальные источники

- Проверить и реализовать безопасный способ получения Ollama Cloud usage из авторизованного аккаунта.
- Реализовать источник ChatGPT Subscription через usage dashboard или поддерживаемый локальный bridge, не сохраняя пароль/cookies.
- Добавить кэш последнего успешного значения и явный stale state.
- Проверить поведение при logout, истечении сессии и изменении структуры dashboard.

## Этап 4 — следующие панели

- Добавить Calendar через EventKit с минимальными разрешениями.
- Добавить Music с текущим треком и базовыми playback-командами.
- Сохранить общий механизм переключения и жизненный цикл panel providers.

## Проверка

- Сборка macOS target в доступном Xcode.
- UI-проверка compact/expanded и переключения панелей.
- E2E-проверка запуска, раскрытия челки, переключения панелей и refresh flow.
- Проверка, что отключение одного провайдера не ломает панель.
