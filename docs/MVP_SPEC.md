# Notch MVP: панели квот

## Цель

Нативное macOS-приложение в виде компактной «челки» в верхней части экрана. По наведению или явному открытию челка расширяется и показывает выбранную панель. Панели переключаются внутри одного окна и добавляются независимо друг от друга.

Первая панель — `Лимиты`. Следующие запланированные панели — `Календарь` и `Музыка`.

## Первая версия

### Оболочка

- SwiftUI-интерфейс с AppKit-координатором окна.
- Прозрачное borderless-окно поверх верхней части экрана.
- Два состояния: компактное и раскрытое.
- Переключатель панелей в раскрытом состоянии.
- Состояния загрузки, ошибки и отсутствия подключения должны быть видимыми.

### Панель «Лимиты»

Показывает карточки двух провайдеров:

1. ChatGPT — квоты подписки.
2. Ollama Cloud — квоты облачного аккаунта.

Каждая карточка может содержать несколько окон квоты. Для каждого окна показываем:

- название или модель;
- доступный лимит, если источник его сообщает;
- оставшееся значение;
- время следующего сброса;
- время последнего обновления;
- источник данных и состояние (`актуально`, `устарело`, `недоступно`).

Для ChatGPT источник — авторизованный usage dashboard подписки. Официально доступный dashboard: `https://chatgpt.com/codex/settings/usage`. Лимиты зависят от модели и временного окна; приложение не должно подменять недоступные значения оценкой.

Для Ollama Cloud источник — авторизованный аккаунт и его usage/settings. По опубликованным правилам Ollama Cloud есть сессионное окно 5 часов и недельное окно 7 дней; расход зависит от модели и обработанных токенов. Конкретные числа берём только из аккаунта.

### Безопасность

- Не сохранять пароль, cookies или session-токены в репозитории, логах и настройках в открытом виде.
- Подключение аккаунта должно быть явным действием пользователя.
- Если для источника нет стабильного публичного API, показывать понятное состояние `требуется авторизация` или кнопку открытия dashboard, а не имитировать live-данные.
- Любые долгоживущие секреты, если они понадобятся в дальнейшем, хранить только в macOS Keychain.

## Архитектура данных

UI не знает деталей конкретного сервиса. Провайдер реализует общий контракт:

- `QuotaProvider` — идентификатор, название, статус подключения, получение snapshot.
- `QuotaSnapshot` — набор окон квоты, время получения и источник.
- `QuotaWindow` — лимит, остаток, reset date, единицы измерения и подпись окна.

Провайдеры должны уметь отдавать `unavailable` и `stale`, сохраняя последнее корректное значение с отметкой времени. Это позволяет добавить другие сервисы без переписывания панели.

## Отложено

- Полноценное чтение календаря через EventKit.
- Управление музыкой и визуализатор.
- Автоматическое добавление новых провайдеров.
- Уведомления о приближении к лимиту.
- Синхронизация настроек между Mac.

## Критерии готовности MVP-оболочки

- Проект открывается как macOS-приложение.
- Челка отображается в компактном состоянии и раскрывается.
- Панели можно переключать.
- Панель «Лимиты» корректно рендерит ChatGPT и Ollama Cloud в состояниях mock/live/unavailable.
- Недоступный источник не блокирует остальные панели.
- Секреты не попадают в исходники и логи.
