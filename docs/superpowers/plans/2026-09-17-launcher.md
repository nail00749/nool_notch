# Nool Launcher Implementation Plan

**Goal:** Add the approved universal Spotlight-style launcher to Nool.

**Architecture:** A separate coordinator and model combine four independent sources.
The app delegate owns its lifetime; the existing settings window hosts its controls.

**Tech Stack:** Swift 6, macOS 14+, SwiftUI, AppKit, Carbon, NSMetadataQuery.

**Spec:** ../specs/2026-09-17-launcher-design.md

## Global constraints

- macOS 14+, no third-party dependencies or private APIs.
- Preserve pre-existing dirty changes and existing window/signing ownership.
- Clipboard is opt-in, bounded, local and excludes concealed/transient data.
- No execution of query text, shell commands or remote clipboard transmission.

## Execution

- [x] Search sources: add LauncherResult, LauncherSearch, LauncherApplicationProvider,
  LauncherFileProvider and LauncherCalculator under Sources/NotchApp/Launcher.
  Source results carry stable IDs, title, subtitle and typed URL/clipboard/calculation
  payloads. Query changes cancel previous file results. Verify exact/prefix/fuzzy
  ranking, malformed arithmetic, zero division and quoted file queries in focused tests.
- [x] Clipboard: add LauncherClipboardStore and focused tests. Inject persistence URL
  and pasteboard for isolation. Verify limits, duplicate suppression, concealed types,
  expiration, corrupt persistence and clear/disable behavior.
- [x] Presentation: add LauncherSettings, LauncherModel, LauncherHotKey,
  LauncherWindowCoordinator, LauncherView and LauncherSettingsView. Register Option-Space
  and surface registration conflicts. Add arrow/Return/Escape/Tab handlers; keep selection
  in bounds as asynchronous results arrive. Test selection and preference validation.
- [x] Integration: initialize one coordinator in NotchAppDelegate; add one launcher
  settings section in NotchSettingsView. Connect open/settings actions without adding
  launcher state to NotchViewModel. Update README and CHANGELOG Unreleased.
- [x] Automated verification: run `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer
  xcrun swift build`, focused `swift test --filter Launcher`, then `git diff --check`.
  Review independently, fix findings, rerun affected checks. Use scripts/run-app.sh
  with existing signing configuration and record live acceptance separately.
- [ ] Complete live acceptance of hotkey, focus return, paste, multiple displays and
  coexistence with Jira popovers. Native computer-use connection failed during smoke
  testing; no successful end-to-end launcher interaction is claimed.

The primary agent owns integration and verification. Bounded source and clipboard
implementation may run in parallel according to AGENTS.md; no secondary workflow gates.

## Verification results — 2026-09-17

- `swift test --filter Launcher`: 30 tests, 0 failures.
- `scripts/run-app.sh`: build passed; bundle signed with existing stable identity and
  restarted. `codesign --verify --deep --strict Build/NotchApp.app` passed with access
  to the system trust store. No signing mode change was made.
- `git diff --check`: passed.
- Independent review found stale-query activation and queued deletion at termination;
  both were fixed and checked with regression tests. No further material findings.
- Native smoke testing observed Nool's existing notch and expanded view. The initial
  synthetic Option-Space event did not establish whether the launcher opened; the
  tool then failed with `Sky Computer Use native pipe closed before response`, also
  after reconnect/reset. Process remained alive with no new crash report.
- User was asked to confirm opening via Option-Space. Clipboard opt-in, paste permissions,
  and existing unrelated preferences were not changed for this smoke attempt.
- Full pre-existing Swift test suite was not run; focused launcher checks are the
  automated acceptance evidence for this change.
