# NooL App

Нативная macOS-челка для быстрых рабочих действий и фоновой информации.
Она закрепляется по центру верхнего края экрана, раскрывается поверх рабочего
стола и объединяет несколько независимых панелей в одном окне.

## Модули

В **Настройки → Модули** выберите нужные инструменты отдельно или примените
готовый набор: «Минимальный», «Разработчик», «Мониторинг», «Все функции».
Набор заменяет текущий выбор; после этого его можно настроить переключателями.
При первом запуске после обновления все модули доступны, а существующие
настройки включения Dock, истории буфера, мониторинга и других функций сохраняются.

Выключение модуля убирает его панели и команды, закрывает связанные окна и
останавливает фоновые задачи. Настройки, учётные записи и история сохраняются
для повторного включения. Само включение модуля не выдаёт разрешения macOS и
не активирует ранее выключенные опции внутри функции.

Launcher, поиск приложений и файлов, калькулятор, Quick Look, общие настройки
и обновления доступны всегда, даже если выключить все модули. Виджеты Dock и
действия между функциями доступны только при включённых соответствующих модулях.
Карточки показывают доступные места отображения; кнопка **Настроить** открывает
существующие настройки функции и её размещения.

Модули встроены в приложение и обновляются вместе с ним.

## Возможности

- В **Настройки → Основные → Тема интерфейса** можно выбрать системную,
  светлую или тёмную тему. Выбор сохраняется и применяется без перезапуска;
  системная тема следует оформлению macOS. Акцентный цвет берётся из macOS.
  Launcher и Dock используют нативные полупрозрачные материалы;
  при включённом «Уменьшении прозрачности» подложка становится непрозрачной.
  Чёлка в компактном и раскрытом состоянии остаётся полностью чёрной со светлым
  текстом, чтобы сливаться с физическим вырезом экрана.
- В настройках дисплеев можно оставить NooL App на встроенном экране, закрепить
  его на выбранном мониторе или перемещать свернутую челку вслед за указателем.
  Для каждого подключённого дисплея можно сохранить отдельную высоту compact-режима.
- Раздел обновлений сравнивает установленную версию с последним публичным
  GitHub Release, показывает описание релиза и копирует точную команду обновления
  Homebrew. Установка не запускается без явного действия пользователя.
- В панели Live — встроенный таймер в стиле «Часов» с выбором часов, минут и
  секунд, паузой, отменой и звуком завершения. Отсчёт и пауза доступны в компактной
  челке; нажатие на время открывает таймер. Он работает внутри NooL App, не связан
  с системными «Часами» и сбрасывается при выходе из приложения.
- За 5 минут до встречи в компактной челке появляются отсчёт и «Войти» при наличии
  ссылки; без ссылки доступен переход в календарь. Напоминание скрывается в момент
  начала встречи. Доступ к календарю нужно один раз разрешить в его панели;
  затем события обновляются в фоне, пока панель календаря включена в настройках.
- Кнопка лупы рядом с вкладками ищет по уже загруженным Jira-задачам,
  AI-сессиям и событиям календаря; Escape закрывает поиск.
- Кнопка полки принимает до 20 файлов и папок: перетащите их на челку или
  нажмите «Выбрать», затем перетаскивайте в нужное приложение. Полка хранит
  ссылки до выхода из NooL App; удаление с полки не удаляет оригинал.
- В списке календаря ближайшая встреча показывает обратный отсчёт и кнопку
  подключения, если в событии есть ссылка Zoom, Google Meet, Teams, Webex,
  GoTo Meeting, Whereby или Jitsi.
- AI-панель с лимитами ChatGPT, Claude Code и Ollama Cloud;
- единый Agent Inbox для Codex Desktop, Codex CLI и Claude Code со статусами
  и Jira-связями; ответы на живые запросы CLI доступны прямо из челки;
- связанные с AI-сессией PR/MR прямо в строке Inbox: CI, конфликты, reviewer
  activity и переход к MR/PR;
- универсальный Now Playing с обложкой и управлением воспроизведением;
- ближайшие события календаря;
- Jira с личными задачами, переходами между статусами и worklog;
- отдельный Jira-режим `Мои / Закреплённые`;
- закрепление Jira-проектов, досок и отдельных задач;
- Live Activities для батареи Mac, AirPods/аудиогарнитур,
  звонков и загрузок браузера;
- настройка внешнего вида компактной челки и запуск при входе в macOS.

В закреплённом Jira-режиме каждый проект или доска отображается отдельным
источником. Для доски загружаются все доступные задачи без фильтра по
исполнителю. Отдельно закреплённые задачи собраны в источнике `Задачи`.

Приложение рассчитано на macOS 14+. Публичный Homebrew-артефакт собирается для
Mac с Apple Silicon. На MacBook используется физическая челка; на внешнем
дисплее или Mac без выреза отображается программный вариант.

В локальных сборках с командной подписью Apple доступен [системный виджет
лимитов](docs/QUOTA_WIDGET.md) для рабочего стола и Центра уведомлений:
кольца остатка, два размера и выбор периода 5 часов / 7 дней. Текущие
публичные ad-hoc/Homebrew сборки этот виджет пока не включают.

## Жесты на чёлке

В **Настройки → Жесты** можно включить прокрутку для изменения системной
громкости и выбрать действие двойного клика: пауза/воспроизведение,
следующий или предыдущий трек. По умолчанию жесты выключены.

Жесты работают на обычной компактной чёлке и на обложке в раскрытой панели
музыки. Кнопки встречи, таймера и маскот сохраняют свои действия. При включённом
двойном клике одиночный клик раскрывает чёлку после короткого ожидания второго
нажатия. На устройствах с фиксированной громкостью, например некоторых HDMI
выходах, изменение громкости может быть недоступно.

## Мониторинг системы

В **Настройки → Мониторинг** включается отдельная боковая панель или угловой
стек с показателями Mac. Выберите сторону/угол, нужные показатели и интервал
обновления 1, 2 или 5 секунд. В покое остаётся только тонкий маркер у края
экрана. Наведите на него указатель: появится боковая волна с кольцами или
веер отдельных карточек, как у AI-лимитов. После ухода указателя показатели
скрываются. В боковой панели наведение на кольцо показывает подробности;
нажатие на CPU или ОЗУ открывает пять самых ресурсоёмких процессов,
а на диск или сеть — настройки мониторинга.
Панель следует выбранному в разделе «Дисплеи» экрану и ищет свободное место
рядом с панелями лимитов. Стек привязан к физическому углу экрана без отступа
от Dock; боковая панель учитывает рабочую область экрана.

- CPU: суммарная загрузка всех ядер, от 0 до 100%.
- ОЗУ: оценка занятой физической памяти без файлового кэша, в процентах и байтах.
  Это не показатель memory pressure из «Мониторинга системы» macOS.
- Диск: занятое место на системном томе данных; обновляется раз в 30 секунд.
- Сеть: текущая скорость приёма и передачи Wi-Fi/Ethernet в байтах в секунду.
  Loopback и виртуальные VPN-интерфейсы не суммируются с физическими повторно.
  Это текущий трафик, а не измерение пропускной способности Speedtest.

CPU и сети нужны два замера: после включения или пробуждения сначала виден
прочерк. Недоступный показатель также отображается прочерком. Мониторинг
выключен по умолчанию, останавливается во время сна/неактивной сессии и при
выключении функции. Показания не сохраняются и не отправляются по сети.

В окне процессов можно переключать сортировку по CPU и резидентной ОЗУ
и открыть системный **Мониторинг системы**. Список обновляется каждые две
секунды только пока окно открыто. CPU процесса использует шкалу «100% = одно
ядро» и может превышать 100%; резидентная ОЗУ включает общие страницы и может
отличаться от столбца «Память» macOS. Недоступные процессы пропускаются.

## Анимация крышки MacBook

В **Настройки → Крышка MacBook** можно включить плавное размытие и затемнение
встроенного экрана при закрытии крышки. Настраиваются начальный угол,
сила размытия и затемнение. **Предпросмотр** показывает эффект в течение
3 секунд, даже если датчик угла недоступен.

По умолчанию функция выключена. Разрешение **Запись экрана** запрашивается
только кнопкой в этом разделе; после выдачи доступа macOS может потребовать
перезапустить NooL App. Кадры обрабатываются локально в памяти, не записываются
в файлы и не отправляются по сети; звук не захватывается.

Реакция на крышку зависит от наличия совместимого HID-датчика конкретного
MacBook. На внешние мониторы эффект не распространяется. При выключении
функции, сне или потере данных датчика наложение скрывается; системный сон
не задерживается. Проверку плавности и совместимости нужно выполнить на
своём MacBook.

## Speedtest

В Launcher нажмите выделенную кнопку **Speedtest** справа от вкладок.
Также можно найти **Speedtest** или **проверка скорости** через поиск и нажать Enter.
В отдельном окне **Проверить оба** запускает сначала Москву (Cloud4box), затем
Франкфурт (Clouvider). Кнопка на карточке проверяет только выбранный сервер.
Результат содержит скачивание, отдачу в Мбит/с, HTTP-задержку и джиттер в мс.
Это измерение маршрута до конкретного сервера; VPN и другие загрузки влияют
на результат. Расположение указано операторами в [Cloud4box Looking Glass](https://lg.cloud4box.com/)
и [каталоге LibreSpeed](https://github.com/librespeed/speedtest/blob/master/server-list.json).

Тест запускается только вручную и активно использует сеть: до 768 МиБ тестовых данных на два
сервера. **Остановить** или закрытие окна отменяет текущие запросы и очередь.
Ошибка одного сервера не препятствует проверке другого. Последний успешный
результат каждого сервера с датой сохраняется локально; неудачный тест его
не перезаписывает. Дополнительные CLI не требуются.

Вкладка **История** хранит последние 200 успешных замеров локально. Доступны
периоды **7 дней**, **30 дней** и **Всё время**, графики скачивания, отдачи
и задержки для обоих серверов. Точки на графике — средние за день; рядом
приведены число замеров и исходные результаты с датами. Прежние последние
результаты переносятся в историю при первом открытии новой версии.
Неудачные и отменённые замеры в историю не попадают.

### Диагностика интернета

Откройте вкладку **Диагностика** в Speedtest или найдите **Диагностика
интернета** в Launcher. Проверка запускается вручную и отдельно оценивает:

- ответ активного IPv4-шлюза на ICMP;
- ответы внешнего адреса `1.1.1.1`, задержку и долю пропущенных ответов;
- разрешение `example.com` системным DNS-резолвером, включая его кэш;
- HTTPS-доступ к `https://example.com`.

На каждый ICMP-тест отправляется пять пакетов. Отсутствие ответа не доказывает
отсутствие интернета: шлюз или внешний узел могут фильтровать ICMP.
При VPN активный шлюз может отличаться от домашнего роутера; отсутствие
IPv4-шлюза не исключает работу через IPv6. Вывод относится к указанным
адресам, а не ко всем сайтам.

Диагностика и Speedtest не запускаются одновременно, чтобы нагрузка одного
теста не искажала другой. Закрытие окна отменяет проверку. Результаты
диагностики не сохраняются; настройки сети не меняются.

## Рабочие пространства

В Launcher откройте **Рабочие пространства** кнопкой вверху или найдите эту
команду поиском. Создайте набор с названием, добавьте приложения, папки и сайты
HTTP/HTTPS, при необходимости выберите уже сохранённую раскладку окон и нажмите
**Сохранить**. Доступно до 20 пространств, по 20 элементов в каждом.

Для запуска найдите пространство по имени в Launcher и нажмите Enter. NooL App
откроет элементы по очереди, дождётся готовности приложений в пределах таймаута
и один раз применит раскладку. Для расположения окон требуется ранее выданный
«Универсальный доступ»; приложения и сайты можно открывать без этого разрешения.
Результат запуска доступен при следующем открытии Launcher и в редакторе.
Запуск можно прервать выходом из NooL App; уже открытые приложения не закрываются.
Наборы хранятся локально и сохраняются между перезапусками.

## Предупреждения о лимитах

В **Настройки → Лимиты → Предупреждения о лимитах** включите нужных провайдеров.
Разрешение macOS на уведомления запрашивается только при включении. Для каждого
источника отдельно доступны пороги остатка **20%**, **10%** и сообщение после
восстановления. При скачке сразу ниже 10% приходит одно критическое предупреждение.

Пока приложение NooL App запущено, включённые источники проверяются в фоне раз в 5 минут,
даже если скрыты в панели. История срабатываний сохраняется между запусками.
Отсутствующие, устаревшие и просроченные данные не вызывают уведомлений;
наступление времени сброса само по себе не означает восстановление лимита.

## Действия с файлами на полке


Откройте полку файлов в челке, отметьте нужные файлы и нажмите **Действия**.
Без отметок используются все файлы на полке. В контекстном меню строки можно
обработать один файл. Доступны сжатие в JPEG, изменение размера, конвертация
PNG/JPEG, сборка изображений в один PDF и пакетное переименование.

Обработка создаёт новые файлы рядом с исходными или в выбранной папке, без
перезаписи существующих файлов. Результаты автоматически добавляются на полку.
Поддерживается до 20 файлов за операцию; папки и символические ссылки не
обрабатываются. Изображения ограничены 64 мегапикселями и стороной 16 384 px;
результат — стороной до 4 096 px. PDF использует показанный порядок файлов.
При конвертации берётся первый кадр, метаданные исходника не переносятся.

Для переименования задайте префикс и начальный номер, нажмите **Предпросмотр**,
затем **Переименовать**. Расширения сохраняются. Конфликт имён или изменение
исходного файла после предпросмотра останавливает операцию. При отмене приложение
пытается вернуть уже переименованные файлы и сообщает, если часть вернуть не удалось.

## Распознавание текста

### Текст с экрана

Нажмите **Текст с экрана** в верхней панели Launcher или найдите эту команду
поиском. Выделите прямоугольную область на одном из мониторов. Escape или
правый клик отменяет выделение. При первом запуске macOS может запросить
разрешение **Запись экрана**; после выдачи доступа может потребоваться перезапуск NooL App.

Выделенная область распознаётся локально и открывается в редактируемом окне.
Изображение остаётся в памяти, не сохраняется в файл или буфер обмена.
Можно скопировать текст, выбрать **Перевести с AI…** для черновика перевода
на русский или **В AI-черновик**, чтобы добавить свой вопрос. Данные передаются
AI только после отдельного нажатия отправки в чате.

### Изображения и PDF

На полке выберите изображения или PDF и нажмите кнопку **Распознать текст**
(без отметок используются все файлы). Для одного файла действие доступно в
контекстном меню; в Launcher выберите файл и нажмите **⌘K → Распознать текст**.

Распознавание выполняется на Mac через Apple Vision. В отдельном окне можно
исправить результат, найти текст и перейти между совпадениями, скопировать его
или открыть AI-черновик. Закрытие окна отменяет работу. Результат OCR не
записывается в отдельную историю; явно переданный AI-черновик сохраняется по
обычным правилам истории чатов. Внешнему AI текст отправляется только после
нажатия отправки в чате.

Поддерживаются PNG, JPEG, HEIC, однокадровый TIFF и PDF, включая сканы. Лимиты:
10 файлов, каждый до 20 МБ, PDF до 40 страниц, изображение до 60 мегапикселей
и 20 000 px по стороне. Для распознавания изображение уменьшается до 2 048 px.
Результат ограничен 100 000 символами, AI-черновик — 12 000; превышение лимита
показывает ошибку без усечения. Для Apple Intelligence может потребоваться
меньший объём текста — чат покажет ограничение выбранной модели.

## NooL Dock

В **Настройки → NooL Dock** можно включить дополнительную панель над системным
Dock. Она использует системные материалы и оформление macOS и не меняет настройки Dock macOS.

- Закрепляйте приложения через «Добавить приложение» и запускайте их нажатием.
- Добавляйте музыку, ближайшую встречу, таймер и заметку. Музыка, события и
  таймер общие с челкой; доступ к календарю запрашивается только по действию
  пользователя. Заметка хранится локально в настройках NooL App.
- Меняйте порядок перетаскиванием или стрелками в настройках. Для каждого
  элемента доступны компактный и обычный размеры, для всей панели — масштаб
  и непрозрачность фона.
- Выбирайте монитор и автоскрытие. При автоскрытии наведите указатель на ручку
  NooL Dock; редактирование заметки удерживает панель открытой.
- Если элементы не помещаются на экране, полоса прокручивается по горизонтали.

## NooL Launcher

Кнопка **Окна и раскладки** рядом с настройками Launcher открывает управление
окнами: левая/правая половина, весь доступный экран (без перехода в macOS Full
Screen), центр и следующий монитор. Команды также находятся во вкладке **Все**
по словам «окно», «слева», «раскладка» и по имени сохранённой раскладки.
Быстрые действия относятся к приложению, из которого вы открыли Launcher.

Для управления разрешите NooL App в **Настройки системы → Конфиденциальность и
безопасность → Универсальный доступ**. Можно сохранить до 12 раскладок.
Они восстанавливают обычные окна уже запущенных приложений; свёрнутые и
полноэкранные окна пропускаются. Окна сопоставляются по приложению, заголовку,
затем порядку. Если монитор отключён, используется основной. Имена окон и
геометрия раскладок сохраняются локально в настройках NooL App.

Нажмите **⌥ Space**, чтобы открыть отдельную панель поиска. Повторное сочетание
или Escape закрывает её; стрелки выбирают результат, Enter открывает приложение
или файл. Tab переключает «Всё», «Приложения», «Файлы», «Буфер» и «AI».
Внутри Launcher **⌘1–⌘5** выбирают эти вкладки напрямую, **Ctrl+Tab** открывает
следующую, **Ctrl+Shift+Tab** — предыдущую с переходом по кругу. Сочетания
работают и при вводе сообщения в AI-чате.

**⌘K** или кнопка **Действия** открывает меню выбранного результата.
Стрелки выбирают действие, Enter выполняет, Escape возвращает результаты.
Те же действия доступны по правому клику. Изменение запроса закрывает меню,
чтобы действие не применилось к результату предыдущего поиска.

Для файла доступен **Предпросмотр** через Quick Look: выберите результат
стрелками и нажмите **пробел**, либо используйте **⌘Y** или меню действий.
При обычном вводе запроса пробел продолжает вводить пробел. В окне
предпросмотра **Escape** или **пробел** закрывает его и возвращает Launcher.
Предпросмотр не изменяет файл.

Для файла доступны Finder, копирование пути, обработка и переименование
с предпросмотром; для поддерживаемых форматов — вложение в AI и OCR.
Для Jira — открытие, копирование ключа, выбор статуса и форма worklog.
Для текста буфера — копирование, вставка, подготовка перевода или объяснения
в AI, сохранение как шаблона. Шаблоны ищутся во вкладках «Все» и «Буфер»,
хранятся локально и независимо от включения или очистки истории буфера.
Сохранение выполняется только явным действием; удалить шаблон можно через
его меню `⌘K`. Лимит — 100 шаблонов по 12 000 символов.
Такие AI-действия сохраняют прежний чат и открывают отдельный черновик;
вы можете изменить запрос и модель перед отправкой.

- Приложения находятся по названию, включая неточные совпадения.
- В разделе «Все» также ищутся уже загруженные задачи Jira, встречи календаря
  и AI-сессии NooL App. Enter открывает задачу или сессию; для встречи показывает
  карточку с датой и кнопкой подключения, если доступна ссылка.
- Чтобы задать AI вопрос прямо из «Все», введите его в строку поиска и нажмите
  **⌥ Enter** или **«Спросить AI»**. Ответ появляется под поиском; его можно
  остановить или скопировать. Первый Escape возвращает результаты поиска.
  Используются провайдер и модель, выбранные во вкладке AI, и только явно
  включённые подключения. Каждый вопрос начинает отдельный чат; прежний диалог,
  черновик и вложения сохраняются в истории, но в новый запрос не попадают.
- Файлы и папки ищутся по имени через системный индекс Spotlight в выбранных
  каталогах. По умолчанию это Рабочий стол, Документы и Загрузки. Контекстное
  меню результата позволяет показать его в Finder.
- Арифметическое выражение, например `(24 + 6) * 7`, показывает результат в
  разделе «Всё». Enter копирует его. Поддерживаются `+`, `-`, `*`, `/`, `^`
  и скобки; команды и код не выполняются.
- История текста и изображений включается отдельно в **Настройки → Launcher**.
  Enter копирует запись, **⌘ Enter** вставляет её в предыдущее приложение.
  Для автоматической вставки требуется Accessibility; без него запись можно
  вставить вручную через ⌘V.

В настройках Launcher можно изменить горячую клавишу, выбрать папки, установить
лимит и срок хранения истории, очистить её или открыть панель кнопкой. История
по умолчанию выключена; после включения хранит до 100 записей за 7 дней, до 5 МБ
на запись и 50 МБ всего. Выключение истории удаляет сохранённые записи.
Содержимое буфера, помеченное приложением как скрытое или временное, пропускается.

Во вкладке **AI** можно выбрать Apple Intelligence, Codex CLI, Claude CLI или Ollama,
читать ответ по мере генерации, остановить его и скопировать. Enter отправляет
сообщение, Shift+Enter добавляет строку. Закрытие панели сохраняет текущий диалог
и черновик. История сохраняется локально в Application Support с правами только
для текущего пользователя. Кнопка часов открывает поиск по диалогам, закрепление
и удаление. «Новый чат» и смена провайдера или модели сохраняют предыдущий диалог
в истории. Лимит — 100 чатов и 20 МБ; старые незакреплённые чаты удаляются при
достижении лимита с уведомлением, закреплённые автоматически не удаляются.
Стартовые подсказки добавляют заготовку в поле ввода, не отправляя её. Поле
растёт при многострочном вводе, а после копирования ответа появляется отметка.

Скрепка рядом с отправкой добавляет файлы; их также можно перетащить в AI-чат.
Перед отправкой видны названия и миниатюры, ненужное вложение удаляется крестиком.
Поддерживаются UTF-8 текст и исходники, PDF с извлекаемым текстом, PNG, JPEG,
HEIC и TIFF. Из PDF извлекается только текст: рисунки, таблицы как изображения
и сканы не распознаются. Страницы без текста помечаются в содержимом документа.
Для разбора скриншота выберите модель с пометкой **«Фото»** — Codex, Claude или
локальную vision-модель Ollama. Apple Intelligence в этом чате принимает только
текст документов. Неподдерживаемое вложение блокирует отправку с объяснением.

Лимиты: четыре вложения, исходный файл до 10 МБ, документ до 12 000 символов,
PDF до 40 страниц. Изображения уменьшаются до 1536 px по длинной стороне,
перекодируются без исходных метаданных и занимают до 2 МБ каждое, до 4 МБ вместе.
Вложения и их черновики сохраняются внутри локальной истории. При смене модели
или провайдера неотправленный черновик с вложениями переносится в новый чат;
отправка происходит только по Enter или кнопке. Для облачных провайдеров
содержимое вложений передаётся выбранному сервису вместе с сообщением.

- Apple Intelligence использует локальную системную модель на совместимом Mac
  с macOS 26+. Если модель отключена, загружается или не поддерживает запрос,
  панель объясняет причину; автоматического перехода в облако нет.
- Ollama использует сервер `http://127.0.0.1:11434` и установленные локальные
  модели. Облачные модели исключены. NooL App не устанавливает сервер и не скачивает
  модели автоматически; после запуска Ollama нажмите «Проверить подключения».
- Подключения Codex и Claude по умолчанию выключены. Включите нужное в
  **Настройки → Launcher → AI-чат**. Требуется установленный современный CLI
  со входом через подписку: `codex login` или `claude auth login`.
  Сообщения и ограниченный контекст текущего диалога отправляются выбранному
  сервису; отдельный API-ключ в NooL App не нужен.
- CLI запускаются в отдельном временном каталоге с отключёнными инструментами,
  MCP, плагинами и hooks. Глобальные конфиги и учётные данные NooL App не меняет.
  Codex получает временную сессию без окружения проекта, Claude — режим
  `--safe-mode` без сохранения сессии. Если изоляцию Codex подтвердить не удалось,
  подключение остаётся недоступным. Старые версии CLI могут требовать обновления.

Сообщения поддерживают до 8 000 символов собственного текста. Длинный
контекст обрезается по целым завершённым парам вопрос–ответ; для локальной модели
Apple лимит меньше. При достижении лимита сообщений или объёма начните
новый чат. Это отдельный чат, он не продолжает сессии Agent Inbox.

Для работы с выделением выберите текст в другом приложении, откройте Launcher
и вкладку AI. Меню с текстовым курсором предлагает перевод на русский,
сокращение, объяснение и исправление. Действие заполняет черновик: проверьте его
и отправьте. Для чтения выделения нужен Accessibility; защищённые поля
пропускаются, предел — 7 000 символов. Ответ можно скопировать или кнопкой
обратной стрелки вставить вместо исходного выделения. Если выделение изменилось,
ответ остаётся в буфере для ручной вставки.

## Установка через Homebrew

Публичные сборки пока подписываются ad-hoc и не проходят notarization, поэтому
при установке нужно явно отключить quarantine:

```sh
brew tap nail00749/tap
brew install --cask --no-quarantine nool-notch
```

После выпуска версии под новым именем запусти **NooL App** из `/Applications` и выдай необходимые
разрешения в System Settings. Homebrew также установит `gh` и `glab`, нужные
панели PR/CI.

Опубликованные ранее версии cask ещё могут устанавливать приложение под старым именем.

Обновление:

```sh
brew update
brew upgrade --cask nool-notch
```

## Подключение Jira

Открой настройки NooL App, выбери раздел Jira и укажи:

- базовый URL Jira Data Center или Jira Server;
- Personal Access Token пользователя.

После подключения можно выбрать проекты для режима `Мои`, закрепить общие
проекты и доски, а также добавить отдельные задачи по ключу, например
`NPA-123`. Токен сохраняется только в macOS Keychain.

## Agent Inbox

Раздел `AI -> Inbox` собирает сессии поддерживаемых coding agents в одну
очередь: отдельно показывает запросы внимания, работающие и недавние задачи.
Из карточки можно открыть Codex-задачу. Для CLI можно разрешить или отклонить
ожидающее действие и ответить на вопрос, если агент передал живой запрос.

Codex Desktop наблюдается по локальной истории: данные помечены как локальные,
а подтверждения и ответы выполняются в самом Codex. Прямой live-канал Desktop
не подключён; время работы по его локальным статусам не начисляется.

Если в git-ветке или пути worktree есть Jira-ключ вроде
`NPA-123`, Inbox показывает рядом текущую задачу и её статус. Из карточки можно
открыть Jira, сменить статус или исполнителя, а после завершения сессии — открыть
заранее заполненный worklog с фактической длительностью работы.
Время учитывается только пока агент действительно работает: ожидание approval,
ответа пользователя или восстановления источника ставит таймер на паузу.

Для Codex CLI и Claude Code интерактивный approval включается явно в
`Настройки -> Интеграции`. После включения приложение устанавливает собственный
небольшой bridge в `~/.nool-notch/bin` и добавляет только свои записи в
существующие hook config. Перед первым изменением рядом создаётся файл с расширением
`.nool-backup`. Обмен между CLI и NooL App идёт через Unix socket текущего
пользователя; сетевой сервис не используется. После первого запуска новой
версии приложения перезапусти уже открытые CLI-сессии, чтобы они подхватили
hooks. При выключении NooL App удаляет свои hook-записи, не затрагивая чужие.

## PR/CI

Раздел `AI -> Inbox` определяет Git-репозиторий и текущую ветку по workspace
каждой AI-сессии. Если для неё найден PR/MR, справа в той же строке появляются
иконки CI, конфликтов, reviewer activity и переход к MR/PR. Code review
сохраняется для трёх уникальных недавно завершённых сессий, поэтому не исчезает
сразу после окончания работы агента. Для GitHub используется `gh`, для GitLab — `glab`.
Поддерживаются GitLab.com и self-hosted GitLab: хост берётся из remote самого
репозитория, поэтому отдельная настройка сервера в NooL App не нужна.

При установке через Homebrew оба CLI устанавливаются автоматически. Открой
`Настройки -> Интеграции`: NooL App проверит доступные хосты и предложит выполнить
однократную авторизацию в отдельном окне Terminal. При сборке из исходников CLI
можно установить вручную:

```sh
brew install gh
gh auth login

brew install glab
glab auth login --hostname gitlab.example.com
```

NooL App не запрашивает и не сохраняет GitHub/GitLab-токены: авторизацией и её
хранением управляет соответствующий CLI. Данные обновляются при открытии панели
и затем раз в 30 секунд, пока панель видима.

## Live Activities

Панель `Live` автоматически показывает активный звонок с прошедшим временем,
загрузки из системной папки Downloads, подключение и отключение AirPods или
другой Bluetooth-аудиогарнитуры и заряд Mac. Свежий старт или завершение на
12 секунд выводит маскота с иконкой события; длительная активность остаётся
в компактной челке и полном списке без постоянной анимации маскота.

Для доставок и таймеров сторонних приложений, у которых нет публичного macOS API,
доступен локальный read-only bridge. Интеграция может записывать файл
`~/Library/Application Support/Nool/live-activities.json`:

```json
{
  "version": 1,
  "activities": [{
    "id": "order-42",
    "kind": "delivery",
    "title": "Доставка",
    "detail": "Курьер в пути",
    "progress": 0.75,
    "updatedAt": 1788450000,
    "expiresAt": 1788453600
  }]
}
```

Поддерживаемые `kind`: `call`, `timer`, `download`, `delivery`, `headphones` и
`battery`. Времена передаются как Unix seconds. NooL App не читает историю Центра
уведомлений и не использует private API других приложений.

## Сборка из исходников

Понадобятся Xcode или Xcode Command Line Tools со Swift 6:

```sh
git clone https://github.com/nail00749/nool_notch.git
cd nool_notch
./scripts/run-app.sh
```

Скрипт собирает executable `NotchApp`, упаковывает его в `Build/NooL App.app`, подписывает
и перезапускает приложение. По умолчанию используется локальный Apple
Development certificate. Если сертификата нет, временную ad-hoc подпись нужно
разрешить явно:

```sh
NOTCHAPP_ALLOW_ADHOC=1 ./scripts/run-app.sh
```

Ad-hoc переподпись может привести к повторному запросу Accessibility-доступа.
Для стабильной локальной подписи передай имя сертификата через
`NOTCHAPP_SIGNING_IDENTITY`.

## Разрешения и данные

- Accessibility используется как fallback для метаданных активного плеера,
  чтения выделенного текста при открытии Launcher, вставки и управления окнами
  по действию пользователя.
- История AI хранится локально; выбранный текст попадает в неё после добавления
  в черновик. В облако сообщения отправляются только при отправке через Codex/Claude.
- История буфера Launcher хранится только локально в Application Support;
  содержимое, запросы и список файлов не отправляются в сеть и не логируются.
- Calendar запрашивается только для показа ближайших событий.
- Jira-токен хранится в macOS Keychain.
- Закрепления Jira и визуальные настройки хранятся в `UserDefaults`.
- Существующая авторизация Claude Code читается только в памяти и не копируется
  в настройки приложения.
- Локальные события Agent Inbox используются только для текущего состояния и
  не записываются NooL App в историю или логи.
- Live Activities читают только текущее состояние CoreAudio, Bluetooth,
  Downloads и локальный bridge; содержимое системных уведомлений не читается.
- PR/CI читает только состояние текущего репозитория через уже авторизованные
  `gh` или `glab`; их credentials не копируются в приложение.
- Проверка обновлений обращается только к публичному GitHub Releases API и не
  использует GitHub-токен.
- Пароли, cookies и токены не должны попадать в репозиторий или логи.

## Разработка

- `Sources/NotchCore` — независимые модели квот.
- `Sources/NotchApp/App` — запуск, настройки, интеграция и оболочка челки.
- `Sources/NotchApp/Features` — функциональные модули: Launcher, AI, Jira,
  Dock, полка файлов, раскладки окон и другие.
- `Sources/NotchApp/Shared` — общие UI/AppKit-компоненты, палитра и файловый доступ.
- `Tests/NotchAppTests` — Swift-проверки, сгруппированные по App и Features;
  `Tests/Signing` — shell-проверки подписи.
- `scripts` — локальный запуск, подпись и упаковка релиза.
- `docs` — спецификации и планы развития.
- `CHANGELOG.md` — пользовательские изменения по версиям.

История изменений находится в [CHANGELOG.md](CHANGELOG.md), подробный контекст
для разработки — в [AGENTS.md](AGENTS.md), а пошаговая публикация релиза и
Homebrew cask — в [DEPLOY.md](DEPLOY.md).

Карта модулей и правила выделения общего кода — в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
