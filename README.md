# NotchApp

Личная macOS-челка с переключаемыми панелями. Первая панель — квоты подписок ChatGPT и Ollama Cloud; панели календаря и музыки уже зарезервированы в интерфейсе.

## Запуск

Открой `Package.swift` в Xcode или запусти:

```sh
./scripts/run-app.sh
```

Скрипт собирает executable, упаковывает его в `Build/NotchApp.app` и открывает приложение. Целевая платформа — macOS 14+.

Если подключено несколько мониторов, челка выбирает встроенный дисплей MacBook. На Mac без встроенного дисплея используется экран под курсором, затем основной экран.

До подключения аккаунтов панель показывает явно помеченные demo-данные и ссылки на официальные dashboard-страницы. Пароли, cookies и session-токены в проект не добавляются.

## Структура

- `Sources/NotchCore` — независимые модели панелей и квот.
- `Sources/NotchApp` — SwiftUI-интерфейс и AppKit-координатор окна.
- `docs/MVP_SPEC.md` — согласованная спецификация.
- `docs/IMPLEMENTATION_PLAN.md` — этапы реализации.
