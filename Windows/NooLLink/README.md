# NooL Link для Windows

Компаньон работает в системном трее и подключается к NooL на Mac через
приглашение из настроек NooL Link. Нужна одна локальная сеть.

## Несколько Mac

Компаньон может быть подключён к нескольким Mac одновременно. Чтобы добавить
ещё один, выберите в трее **Подключить ещё один Mac…** и вставьте приглашение
из настроек NooL Link на этом Mac. Скопированное на Windows уходит во все
подключённые Mac; скопированное на любом Mac появляется в буфере Windows.
Одна и та же копия, пришедшая сразу с двух Mac (например, через Universal
Clipboard между ними), вставляется один раз. Каждый Mac показывается в меню
трея со своим состоянием; там же его можно отвязать.

## Отправка файлов из Проводника

В меню NooL Link в трее включите **Пункт «Отправить → NooL Link» в Проводнике**.
Затем выделите файлы и выберите **Отправить → NooL Link — <имя Mac>** в меню
правой кнопки: для каждого подключённого Mac создаётся свой пункт.
В Windows 11 стандартное подменю «Отправить» доступно через **Показать
дополнительные параметры**. Для удаления пункта выключите тот же переключатель.
Пункт принадлежит текущему пользователю и не требует прав администратора.
Если переместили `NooLLink.exe`, выключите и повторно включите пункт, чтобы
обновить путь к приложению.

Если приложение уже работает, выбранные файлы передаются существующему
процессу. Если оно закрыто, команда запускает его; при отсутствии сопряжения
нужно сначала подключить Mac. Наборы выбранных файлов отправляются по очереди.
Поддерживаются до 64 обычных файлов суммарно до 32 МиБ на одну отправку;
папки и ссылки пока не поддерживаются. На Mac должна быть включена передача
файлов в настройках NooL Link. Явная отправка сохраняет файлы в папке получения
и не меняет буфер обмена.

Файлы, отправленные с Mac (в том числе через AirDrop в Finder), сохраняются в
папку «Загрузки»; при совпадении имени добавляется номер, например
`Отчёт (2).pdf`. Нажатие на уведомление показывает файл в Проводнике, а пункт
**Открыть полученные файлы** в трее открывает «Загрузки».
Повторный запрос подтверждается без повторного сохранения той же передачи.
При ошибке или отмене уведомление предлагает повторить отправку; автоматической
повторной отправки выбранных файлов нет.

## Сборка

Требуется .NET 10 SDK:

```powershell
dotnet publish Windows/NooLLink/NooLLink.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Проверка на Windows перед выпуском: включить и убрать пункт Проводника,
отправить один файл и выделение из нескольких файлов при закрытом и работающем
приложении, проверить имена с пробелами и Unicode, отмену паузой, недоступный Mac
и повторную доставку после потерянного подтверждения. Кросс-сборка на macOS
не проверяет работу Проводника и системного трея.
