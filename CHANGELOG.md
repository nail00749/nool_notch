# Changelog

Все заметные изменения Nool Notch фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.3.0] - 2026-09-08

### Added

- В карточке лимитов ChatGPT появился независимый прогноз глобального Codex reset
  на 24 и 48 часов с временем последнего подтверждённого сброса и ссылкой на источник.
- Таймер в панели Live оформлен в стиле macOS «Часы»: выбор часов, минут и секунд,
  компактная карточка с барабанами выбора времени, оранжевое кольцо, пауза и отмена.
  В компактной челке доступны отсчёт и пауза;
  завершение сопровождается звуком.
- За 5 минут до встречи компактная челка показывает обратный отсчёт и кнопку входа;
  календарь обновляется в фоне при уже выданном доступе, запросы внимания AI имеют приоритет.
- Временная полка принимает до 20 файлов перетаскиванием или через выбор; файлы можно перетащить из неё в другие приложения, оригиналы остаются на месте.
- Общий поиск находит загруженные Jira-задачи, AI-сессии и события календаря.
- В календаре появилась ближайшая встреча с обратным отсчётом и кнопкой подключения при наличии ссылки.
- Наведение на челку сопровождается лёгким тактильным откликом, полное раскрытие — более выраженным двойным импульсом.
- Добавлена панель `Live` с системными активностями: батареей
  Mac, AirPods и Bluetooth-аудио, звонками и загрузками браузера.
- Для доставок и таймеров сторонних приложений добавлен безопасный локальный
  JSON bridge без чтения системного Центра уведомлений и private API.
- Активный таймер, звонок, загрузка и предупреждение о низком заряде занимают
  compact-зону; свежий старт или финиш системного события сопровождает машущий
  маскот Nool с тематической иконкой.

### Changed

- Задержку раскрытия наведением можно выбрать в настройках: выключено, 0,5, 1 или 1,5 секунды.
- Нулевые счётчики вкладок скрыты; обычные счётчики приглушены, цветом выделены запросы внимания и просроченные задачи.
- Близкие уведомления объединяются в один показ маскота до 12 секунд без повторного появления;
  запросы внимания агента имеют приоритет, а все события остаются в своих панелях.
- Вкладки панелей стали компактнее и прокручиваются горизонтально без обрезания названий.
- Наведение слегка увеличивает челку; полная панель открывается по клику
  или после выбранной задержки (по умолчанию 0,5 секунды) непрерывного наведения.
- Уведомления Live Activities в компактной челке показывают 3D-маскота без текста.
- Кибер-йорк получил более реалистичную модель с заострённой мордой,
  согласованными оттенками шерсти и меньшим числом полигонов; взмах лапой
  сохранён для уведомлений и маскота возле настроек.

### Fixed

- Локальная история Codex Desktop больше не выдаётся за live-подключение;
  ответы и подтверждения Desktop предлагается выполнять в самом Codex.
- Запоздалые ответы Jira после смены подключения больше не сбрасывают новую
  авторизацию и не возвращают старые карточки или закрепления в интерфейс.
- Обновление лимитов Ollama заново загружает страницу; при сбое сохраняются
  последние данные с прежним временем обновления и отметкой об устаревании.
- Краткие Bluetooth-индикаторы исчезают через 12 секунд без ожидания нового
  системного опроса.
- Убрана пауза с пустой чёрной панелью: содержимое появляется одновременно с раскрытием.
- Раскрытие использует единую форму челки по фактическому размеру окна вместо смены
  двух фонов; уменьшено движение содержимого и убран вертикальный отскок поверхности.
- Переход от наведения к раскрытой панели стал плавнее: убраны промежуточное сжатие
  челки и масштабирование панели, согласованы анимации окна и содержимого.
- Исправлено раскрытие по клику на пустую область компактной челки.
- Исправлено завершение приложения при запуске Bluetooth-источника Live Activities:
  добавлено объяснение доступа к Bluetooth для системного запроса разрешения.

## [0.2.0] - 2026-09-03

### Added

- Раздел `AI -> Inbox` объединяет активные и недавние сессии Codex Desktop,
  Codex CLI и Claude Code и группирует их по необходимости внимания.
- Запросы разрешения и вопросы Codex можно обработать прямо в челке; для
  Codex CLI и Claude Code добавлен локальный hook bridge без сетевой передачи.
- Agent Inbox автоматически связывает AI-сессию с Jira-задачей по ключу в
  git-ветке или worktree и предлагает worklog по длительности
  завершённой сессии.
- Для связанных Jira-задач учитывается активное время работы агента с паузами
  на ожидание подтверждения, ответа пользователя и недоступность источника.
- Строка AI-сессии показывает связанный PR/MR через компактные иконки CI,
  конфликтов и reviewer activity с быстрым переходом к MR/PR; GitLab
  поддерживает в том числе self-hosted инсталляции.
- В настройках появился раздел `Интеграции`, который проверяет установку и
  авторизацию `gh`/`glab`, автоматически находит self-hosted GitLab по remote и
  открывает безопасную интерактивную настройку в Terminal.

### Changed

- В AI оставлены две компактные вкладки `Лимиты` и `Inbox`; отдельная PR/CI-зона
  удалена, а состояние code review привязано к соответствующей AI-сессии.
- Счётчики Agent Inbox собраны в компактную горизонтальную строку слева от
  переключателя `Лимиты / Inbox`.
- Действия Jira внутри AI-сессии заменены компактными иконками с сохранением
  кликабельной зоны 40 pt.
- Inbox сохраняет code review для репозиториев трёх последних завершённых
  AI-сессий, чтобы MR и его pipeline не исчезали сразу после окончания работы.
- Homebrew-установка Nool автоматически устанавливает `gh` и `glab`; от
  пользователя требуется только однократная авторизация нужного хоста.
- Интерактивные CLI hooks теперь включаются только явно в настройках; отключение
  удаляет записи Nool, сохраняя чужую конфигурацию.
- Строка Inbox разделена на три компактные колонки: данные сессии и заголовок
  связанной Jira-задачи, время с GitHub/GitLab-индикаторами и Jira-задача с
  сеткой действий 2x2.
- Невидимая hover-зона компактной челки увеличена по бокам и снизу без изменения
  её видимого размера.

## [0.1.5] - 2026-09-03

### Added

- В свёрнутой челке появился нативный анимированный 3D-маскот Nool в образе
  кибер-йорка, созданного по фотографии; он сообщает о завершении AI-сессии или
  необходимости внимания и открывает `AI -> Сессии`.
- В раскрытой челке Nool может постоянно махать возле кнопки настроек; отображение
  включается и выключается в разделе оформления.

### Changed

- В списке Jira и меню переходов теперь явно отображается текущий статус задачи.
- В списке Jira теперь виден текущий исполнитель, которого можно сменить через
  поиск, назначить на себя или снять с задачи.
- При появлении и скрытии маскота компактная челка плавно изменяет ширину на
  50 pt с каждой стороны и высоту на 12 pt, сохраняя привязку к верхнему центру
  экрана.

## [0.1.4] - 2026-09-02

### Added

- Вкладка `Лимиты` преобразована в `AI` с разделами `Лимиты` и `Сессии`.
- Добавлен read-only мониторинг активных и недавних сессий Codex Desktop с
  live-статусами и переходом в выбранный task.
- Источники AI-сессий подключаются через общий расширяемый слой для будущей
  поддержки CLI и других coding agents.

### Changed

- Добавлена единая документация проекта, release runbook и обязательное ведение
  changelog для пользовательских и операционных изменений.

## [0.1.3] - 2026-09-02

### Added

- Добавлен Jira-режим `Мои / Закреплённые`.
- Добавлено закрепление Jira-проектов, досок и отдельных задач.
- Для закреплённых досок добавлен просмотр всех доступных задач без фильтра по
  исполнителю.

### Fixed

- Команды и текст запросов AI-сессии больше не попадают в approval UI или
  описание Jira worklog.
- Выбранные Jira-проекты в режиме `Мои` больше не исчезают из фильтра, если в
  текущей выдаче нет открытых задач; каталог снова загружается через Jira
  Projects API.
- Закрытие Jira popover больше не сдвигает компактную челку в сторону во время
  сворачивания.

## [0.1.2] - 2026-09-01

### Added

- Добавлена настройка высоты компактной челки.

## [0.1.1] - 2026-09-01

### Added

- Добавлена иконка приложения в локальную и публичную сборку.

## [0.1.0] - 2026-09-01

### Added

- Опубликован первый Homebrew-релиз Nool Notch для Apple Silicon.
- Добавлены панели лимитов, календаря, Now Playing и Jira.
- Добавлены arm64 release packaging, checksum и ad-hoc подпись.
